## 🔢 About the Project

A **demo calculator** used in my training sessions to teach programming fundamentals — functions, conditions, loops and input validation — through a project everyone understands.

## ✨ Key Features

- ➕➖✖️➗ Basic arithmetic operations
- 📐 Square, square root and percentage
- 🧯 Graceful error handling
- 🧑‍🏫 Clean code for classroom demos
